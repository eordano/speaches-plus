# 040-align-en-words

English forced alignment via `/v1/audio/transcriptions`. Asserts SRT
structure (timestamp format, monotonicity, segment count target) with a
±100 ms timing tolerance once the real STT/aligner is wired.

## Input artifact

`audio.wav` — 2 s, 16 kHz mono, 3 sine bursts at 440/523.25/659.25 Hz.
Regenerated by `./generate_audio.py`. The audio content does not need to
match the transcript; we assert SRT *shape*, not transcription correctness.

## What it asserts

- Route returns 200 with `Content-Type: text/plain`.
- Body is parseable SRT (segment numbers `\d+`, timestamps `HH:MM:SS,mmm`,
  blank-line separators).
- Segment numbers strictly increasing from 1.
- Per-segment `start <= end`.
- First segment starts ≤ 100 ms; last segment ends within ±100 ms of
  `audio_duration_ms = 2000`.
- Segment count is `3 ± 1` (real-model assertion only).

## Placeholder mode

In placeholder mode (no STT/aligner wired), the route may not exist or may
return a non-SRT body. The fixture is `skip_when_no_model: true` so the
runner reports `[SKIP]` instead of `[FAIL]`. The reference SRT skeleton
in `ref_outputs.reference_srt_skeleton` documents what "passing" looks
like once the aligner is wired.
